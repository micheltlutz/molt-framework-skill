# Privacy

The `molt-framework` plugin is a set of Markdown files that Claude reads as instructions. It contains no hooks, MCP servers, scripts or commands, and it makes no network requests of its own.

- It does not collect, store or transmit personal data, telemetry or usage data.
- It does not read your files itself. When the skill is in use, Claude may read files in your project (for example `Cargo.lock`) under your normal Claude Code permissions, the same as for any other task.
- It is not directed at, or designed for, people under 18.

Anything you send to Claude while using the plugin is handled under Anthropic's own privacy policy, not by this plugin.

Questions: open an issue at <https://github.com/micheltlutz/molt-framework-skill/issues>.
